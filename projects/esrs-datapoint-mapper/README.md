# ESRS Datapoint Mapper & Gap Analyser

An interactive portfolio prototype for the first, messy step in CSRD reporting: turning client evidence into a reviewable ESRS datapoint map and a materiality-scoped gap list.

## What the demo shows

- A synthetic FY 2025 engagement focused on ESRS E1 (Climate change) and S1 (Own workforce).
- Source-linked facts with quoted evidence, confidence, rationale and a three-action review flow: approve, edit or reject.
- Deterministic gap status based on approved mappings and selected material topics.
- Draft client data requests grouped by function, plus CSV exports for maps, gaps, requests and audit events.
- CSV fact intake that adds records to the review queue.

## Prototype boundary

This is a browser-only demonstration with synthetic data. Mapping suggestions are illustrative seed data, not generated by a live model. CSV intake accepts already-extracted fact records; it does not parse XLSX, PDF or DOCX files. Decisions are stored in the current browser's local storage. No client information should be entered.

A production version would add secure engagement accounts, document parsing/OCR, a versioned EFRAG datapoint library, constrained retrieval and LLM mapping, and EU-resident storage. Every suggestion would still require a named human reviewer.

## Product principle

Automate the reading and first-pass organization. Keep materiality judgments, mapping decisions and assurance accountability with the consultant.
